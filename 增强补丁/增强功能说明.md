# 增强补丁使用说明

本目录提供 5 项游戏内增强功能。按需取用，互不影响。

| 功能 | 方式 | 是否需要修改游戏文件 |
|------|------|------|
| TAB 地图调深浅 | 游戏自带快捷键 | 否 |
| 游戏界面显示帧数 | RTSS 外挂显示 | 否 |
| 暗金装备变紫色 | 补丁程序改调色板 | 生成 d2_patch.mpq |
| 金币上限改 1 亿 | 补丁程序改 D2Common.dll | 是（自动备份） |
| 简体中文界面 | 见下文说明 | 视情况 |

---

## 一、TAB 地图调深浅颜色（游戏自带，无需任何修改）

原版暗黑2 内置地图浓淡调节，按 **F10** 即可在三档之间循环切换：

| 档位 | 效果 |
|------|------|
| 无衰减 | 整张地图最浓、最清晰 |
| 中心衰减 | 角色周围半透明 |
| 全部衰减 | 整张地图变淡、最不挡视线 |

也可以在菜单里设置：**选项 Options → 视频选项 Video Options → 自动地图选项 Automap Options → 衰减 Fade**，选 NO / CENTER / EVERYTHING，效果同上。

> 提示：D2DX 高清渲染下该功能正常可用，与分辨率无关。

---

## 二、游戏界面显示帧数（数字）

D2DX / d2fps / PlugY 均**没有**内置帧数显示功能（网上一些文章说的 `show_fps` 配置或 F11 热键经核实并不存在，请勿轻信）。

成熟方案是使用 **RTSS（RivaTuner Statistics Server）**——显卡屏显工具，可在任何游戏画面上叠加 FPS 数字，不改动游戏任何文件：

1. 下载安装 RTSS（MSI Afterburner 安装包内含；也可单独下载 RTSS）：
   - MSI Afterburner: https://www.msi.com/Landing/afterburner
   - 独立 RTSS: https://www.guru3d.com/files-downloads/rtss-rivatuner-statistics-server-download.html
2. 运行 RTSS，左下角 **Setup（设置）**：
   - **Application detection level（应用检测级别）调到 None 或 Low**（暗黑2 是老的 Glide/Direct3D 接口，检测级别高会不显示）
   - 点 **Add（添加）**，浏览选中游戏的 `Game.exe`（或 `Diablo II.exe`）
3. 右侧 **On-Screen Display（屏显）**：
   - Show On-Screen Display 设为 **On**
   - Framerate 设为 **On**
   - 可按喜好设置显示位置、颜色、字体大小
4. 进游戏即可在屏幕角落看到实时帧数。

> 单机使用完全安全；RTSS 与 D2DX 宽屏无冲突。

## 三、暗金装备颜色改成紫色

### 效果
所有暗金（独特）装备的名字（包括未鉴定的、掉落在地上的、箱子里的）由暗金色变为紫色。

### 使用方法（二选一）

**方式 A（推荐，自动完成）**：
1. 把 `PatchUniquePurple.exe` 复制到游戏目录（与 `Game.exe`、`d2data.mpq` 同级）；
2. 双击运行，看到"完成"即可；
3. 程序会自动生成 `d2_patch.mpq`，游戏启动时自动加载，无需加启动参数。

**方式 B（手动）**：用 MPQEditor 打开游戏目录的 `d2data.mpq`，提取 `data\global\palette\ACT1~ACT5\` 下的 `.pl2` 文件，用十六进制编辑器把偏移 `6B60C` 处的 `C7 B3 77` 改为 `AE 00 FF`，再放进新建的 `d2_patch.mpq`。

### 卸载
删除游戏目录下的 `d2_patch.mpq` 即可，不影响其他任何文件。

### 原理（供参考）
暗金名字的颜色不在文本文件里，而是由调色板 `.pl2` 文件末尾的"文本颜色表"决定：表内第 4 项（文件偏移 0x6B60C）默认 `C7 B3 77`（暗金），本补丁改为 `AE 00 FF`（紫）。

## 四、背包/储物箱金币上限改成 1 亿

### 原版限制
- 储物箱每页金币上限固定 **250 万**（1.13c 起）；
- 人物携带金币上限 = 等级 x 10000（99 级约 99 万）。

### 修改后
- 储物箱每页上限 **1 亿**；
- 人物携带上限 = 等级 x 250 万（1 级即有 250 万，99 级约 24.75 亿）。

### 使用方法（二选一）

**方式 A（推荐，自动完成）**：
1. 把 `PatchGoldLimit.exe` 复制到游戏目录（与 `Game.exe`、`D2Common.dll` 同级）；
2. 双击运行，显示"修改完成"即可；
3. 程序会自动备份 `D2Common.dll`（生成 `.bak_日期时间` 文件）后再修改。

**方式 B（手动，十六进制）**：
用十六进制编辑器打开 `D2Common.dll`：
| 查找 | 替换为 | 说明 |
|------|--------|------|
| `B8 A0 25 26 00` | `B8 00 E1 F5 05` | 储物箱上限 250万→1亿 |
| `69 C0 10 27 00 00` | `69 C0 A0 25 26 00` | 人物携带乘数 10000→250万 |

### 卸载 / 还原
运行 `PatchGoldLimit.exe -restore`，或把备份的 `.bak` 文件改名回 `D2Common.dll`。

### 注意事项
- 修改的是游戏代码文件，**务必保留自动备份**；
- 游戏版本更新（重装/打新补丁）后需重新运行本工具；
- 若程序报告"未找到"原版指令，说明你的版本较特殊，请把游戏版本号告诉开发者。

## 五、游戏界面简体中文

**如果你玩的已经是中文版**：无需任何操作，界面就是简体中文。PlugY 的语言选项（`PlugY.ini` 中 `SelectedLanguage=CHI`）可在已安装多语言文件的前提下切换 PlugY 界面语言。

**如果你玩的是英文版，想变成简体中文**：
- **推荐做法**：直接用暴雪官方中文客户端。打开战网桌面端 → 暗黑破坏神2 → 选项/游戏设置 → 语言选"简体中文"，官方中文免费提供，与本工具箱（D2DX 等）完全兼容，零风险零麻烦。
- 不推荐从第三方站点下载来历不明的"汉化包"覆盖游戏文件——来源不明的 `.tbl`/字体文件有安全风险，且版本不匹配会出现"????"乱码。

> 本工具箱的说明文档本身就是简体中文。

## 六、附：PlugY 大箱子（可选安装）

`PlugY_The_Survival_Kit_v14.03.zip` 是著名的单机增强插件，提供 10x10 大箱子、多页储物箱、共享箱、洗点、单机天梯符文之语等功能。

### 安装
1. 解压 zip 到游戏目录；
2. 用记事本打开 `PlugY.ini`，把 `[LAUNCHING]` 节的 `Param=` 改为：
   ```
   Param=-3dfx
   ```
   （让 PlugY 启动游戏时自动带上 D2DX 所需的 -3dfx 参数）
3. 双击 `PlugY.exe` 启动游戏（不要再双击 Play_HD.bat，二者选其一）。

### 注意事项
- PlugY 自带的金币逻辑不改上限，"金币上限 1 亿"请仍用第四节的补丁工具；
-  PlugY 与 D2DX 兼容，但不要同时再用其他帧率补丁；
- 卸载：删除 PlugY.dll、PlugY.exe、PlugY.ini 和 PlugY 文件夹即可。
