## 四、安装步骤（3 步）

1. **找到游戏目录**：就是 `Game.exe` 所在的文件夹。
2. **复制文件**：把本工具箱根目录的文件（不含 `增强补丁` 文件夹）复制进游戏目录。
3. **双击 `恢复高清渲染器.reg`** 导入注册表 → 双击 `Play_HD_PlugY.bat` 开始游戏。

> 不想导入注册表？在原来的快捷方式目标后面加一个空格和 `-3dfx` 即可，例如：
> `"D:\Diablo II\Game.exe" -3dfx`

## 五、分辨率与宽屏说明（重要，请读完）

**v2.0 默认 5 档分辨率**：`640×480` / `800×600` / `856×480` / `1024×768` / `1068×600`

**工作方式**：游戏以 800×600 逻辑分辨率运行，SGD2FreeRes 把全部界面元素按宽屏重新布局（角色选择、物品栏、技能树等），D2DX 按**保持宽高比**的方式放大铺满屏幕——画面不变形、不拉伸。

**为什么默认不含 1920×1080？**
实测发现：把 1920×1080 等更高分辨率写进清单并选用后，在 **Intel UHD 620 等集成显卡**上，进入单人游戏会**卡死在人物选择界面**（进程挂起，表现为黑屏/无响应）。独立显卡未全部验证，故 v2.0 采用保守的稳定清单。

**想用原生 1080P？** 可以自己尝试（有风险，先备份）：
1. 用记事本打开 `SGD2FreeRes.json`，在 `"Ingame Resolutions"` 里加入 `"1920x1080"`；
2. 把 `"Ingame Resolution Mode"` 改成 `1920x1080` 在列表中的序号（从 0 开始数，注意程序会先排序去重）；
3. 用 `Play_HD_PlugY.bat` 启动测试。**一旦卡死**：把本仓库的 `SGD2FreeRes.json` 覆盖回去即可恢复。

## 七、常见问题

**Q1：还有黑边？**
- 确认用 `Play_HD_PlugY.bat`（或带 `-3dfx` / 已导入注册表）启动。
- v2.0 的宽屏是"界面重排 + 保持比例放大"，不是原生 1080P 渲染；追求铺满每一像素需按第五节自行尝试高分辨率。

**Q2：画面被拉伸、人物变胖？**
不会。D2DX 强制保持宽高比（`d2dx.cfg` 里 `nokeepaspectratio=false`）。

**Q3：启动报错 "Unsupported graphics mode"？**
暴雪战网下载版 1.14d 的已知限制，需要额外处理。

**Q4：不喜欢高帧率/运动预测（画面有拖影）？**
`d2dx.cfg` 里把 `nofpsmod=false` 改成 `nofpsmod=true`，或直接删掉 `d2fps.dll`。

**Q5：画面太糊或太锐？**
`d2dx.cfg` 里 `filtering`：`0`=高清锐利（默认）｜`1`=双线性（柔和）｜`2`=Catmull-Rom｜`3`=邻近（像素风）。

**Q6：进游戏后不出人物选择界面，黑屏/闪退/无响应？（v2.0 重点修复）**
按以下顺序排查：
1. **分辨率问题（最常见）**：`SGD2FreeRes.json` 里选用/添加了 1068×600 以上的真高分辨率（如 1920×1080），部分集显会挂起。用本仓库的 `SGD2FreeRes.json` 覆盖游戏目录里的同名文件，重启游戏。
2. **启动方式**：改用 `Play_HD_PlugY.bat`。
3. **注册表**：双击 `恢复高清渲染器.reg` 恢复 Render=3；或打开注册表，把 `HKCU\Software\Blizzard Entertainment\Diablo II\VideoConfig` 下的 `Render` 改成 `1`（Direct3D）或删掉该项（回老渲染路径）应急。
4. **游戏版本太老**：分辨率功能需要 1.09d 以上。

**Q7：首次启动后 `SGD2FreeRes.json` 被游戏自动重写了？**
正常现象，模块会自动补全默认字段，你设置的分辨率列表不会丢。

**Q8：和我已有的 PlugY 冲突吗？**
不冲突，可共存。`Play_HD_PlugY.bat` 就是走 PlugY 链的。

**Q9：如何卸载？**
删除游戏目录里的 6 个文件 + `恢复高清渲染器.reg` 导入的注册表项（或删除 `VideoConfig` 子键），不影响存档。

已经通过 `Patch_D2.mpq`（游戏优先级最高的数据包）打好，**原版 MPQ 未做任何改动**，可完整回滚。
